# resume-craft — 简历秒出

## 两种模式

| 模式 | 触发方式 | 流程 |
|:----|:--------|:----|
| **优化模式** | 用户直接粘贴简历 | 识别内容 → STAR重构 → 去AI味 → 出优化版 |
| **新建模式** | 用户说"新建"或"没简历" | 依次提问 → 根据回答生成 → 去AI味 → 出完整版 |

## 模式一：优化模式（有简历）

用户粘贴简历，说目标方向，skill 根据内置映射表快速调整。

## 模式二：新建模式（没简历）

用户说"新建"或"没简历"后，先展示参考格式，然后让用户一次性发送所有信息。

### 参考格式（展示给用户看）

让用户按以下格式发一段话，skill 自动解析（以下仅为格式示例，纯虚构）：

```
教育：家里蹲大学 硕士 看电视专业
教育：啥也不是学院 本科 睡觉科学与技术
工作：某某公司做高级摸鱼师，负责躺着等下班，带队摸鱼5人
工作：不知名科技公司做PPT美化工程师，负责把一页PPT做成80页
项目：炸厨房项目，当组长，带队把厨房烧了3次，成功获得外卖会员卡
项目：研究为什么猫不喜欢黄瓜，通过实地走访发现原来猫不傻
证书：小区保安资格认证 2025年
奖项：小区广场舞大赛三等奖 2024年
求职：期望不用上班岗，钱多事少离家近
```

### 教育时间自动推算规则

| 学历 | 学制 | 示例 |
|:----|:----|:----|
| 硕士/研究生 | **3年**：入学2024.09 → 毕业2027.07 | 用户说"硕士 公共管理" → 算出2024.09-2027.07 |
| 本科 | **4年**：入学2017.09 → 毕业2021.07 | 用户说"本科 计算机" → 算出2017.09-2021.07 |
| 大专 | **3年**：入学2018.09 → 毕业2021.07 | 用户说"大专 会计" → 算出2018.09-2021.07 |
| 博士 | **4年**：入学2023.09 → 毕业2027.07 | |
| 如果用户写了具体时间 | **优先用用户写的** | 用户写"2023-2025" → 用这个 |

用户只需要说学历+学校+专业，时间自动算，不用手动写。

### 人话 → STAR 自动拆解规则

用户说大白话，skill 自动拆成结构。示例：

```
用户说："我在会计师事务所做审计，查移动省公司的账，发现他们违规发钱，
我还当副组长带了几个人"

skill 自动识别：
  公司：某某公司
  岗位：高级摸鱼师
  S：在没事找事项目中
  T：作为摸鱼组副组长，带队发呆X人
  A：负责研究如何把简单事情变复杂
  R：成功把3天的工作拖成了3周
```

**识别规则：**
- "做/负责/担任" → 职责描述
- "发现/查出/实现/完成" → 成果数据
- "带/管/负责XX人" → 带队经验
- "在XX公司" → 单位名称

### 证书/获奖

只收文字，不收图片。格式：
```
证书：CISP 2025年1月
奖项：省二等奖 2025年
```

## 内置岗位映射表（优化和新建都用）

| 用户说 | 侧重方向 |
|:------|:--------|
| `审计岗` / `IT审计` / `内控` | 突出审计/风控/合规相关经历 |
| `数据分析` / `数据岗` | 突出数据处理/分析工具/量化成果 |
| `信息安全` / `安全岗` | 突出安全认证/安全项目经历 |
| `综合管理` / `党群` / `行政` | 突出管理/协调/公文/党员 |
| `通用` / 没给方向 | 综合展示所有亮点 |
| `银行` / `金融` / `证券` | 突出审计/风控/数据分析 |

## STAR 法则（两种模式都用）

每段经历按 S-T-A-R 重写，**强动词开头**：
主导、负责、设计、实现、优化、推动、协调、搭建、制定、建立、管理、统筹、执行、部署、落地、带队、完成

- S：一句话背景
- T：职责角色
- A：强动词开头，具体行动
- R：每段至少一个量化数据

## 去 AI 味（必须执行）

- ❌ 夸大表述 → 实写
- ❌ "效果显著" → 具体事实
- ❌ "通过…"模板 → 直接写做了什么
- ❌ "为公司做出贡献" → 具体行动+结果
- ❌ "不仅…更…"、"致力于"、"聚焦于"等模板句
- ✅ 每句话有实质信息

## 输出

输出完整简历（新建模式）或优化版简历（优化模式），开头标注：
- 模式：新建/优化
- 目标岗位：
- 处理：STAR重构 + 去AI味
